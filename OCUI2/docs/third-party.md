# Third-party components

| component | license | use |
|---|---|---|
| [Godot Engine](https://godotengine.org) 4.7.2 (.NET) | MIT | the engine the window runs on (not in the repository: `engine\get_engine.ps1`) |
| [Orbitron](https://github.com/theleagueof/orbitron) | SIL Open Font License 1.1 (`OverCompressingUI/assets/fonts/OFL-Orbitron.txt`) | display face: column headings, chips, dialog titles |
| [Exo 2](https://github.com/NDISCOVER/Exo-2.0) | SIL Open Font License 1.1 (`OFL-Exo2.txt`) | the text face |
| [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono) | SIL Open Font License 1.1 (`OFL-ShareTechMono.txt`) | the log and the damage report |

The fonts were taken from the [Google Fonts repository](https://github.com/google/fonts) (`ofl/`). Everything else the
window shows (the backdrop, the veil, the icons, the particles, the sounds) is generated by shaders and code in this
repository; no texture or sound file is downloaded or bundled.
